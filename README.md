# SkillUp Football

A football training website for learning skills by difficulty, then seeing where to use them and when.

## What’s on the site

- **Home** — about the project, photos, and login
- **Skills** — football skills from difficulty 1 (daily basics) to 5 (elite)
- **Where to use it** — situation and perfect timing for every skill
- **Videos** — match examples and pitch animations

## Run it locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
